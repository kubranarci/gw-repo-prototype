# Database Configuration
# 
# This directory uses the consolidated .env file from the project root.
# A symlink (.env -> ../.env) has been created automatically.
#
# To change database settings, edit the root .env file:
#   - POSTGRES_PASSWORD
#   - POSTGRES_DB
#
# To regenerate all configuration, delete the root .env file and run:
#   docker compose run --rm api python migrate.py
